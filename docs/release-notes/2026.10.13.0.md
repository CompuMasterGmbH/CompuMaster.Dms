# CompuMaster.Dms 2026.10.13.0

These notes cover the complete changes since DMS 2026.10.11.0, commit 97c897f172149a585776466fe85fa13f5a9de87f. CompuMaster.Dms.Providers and CompuMaster.Dms.BrowserUI are the affected packages. Existing public/synchronous APIs and default native behavior are retained.

- CompuMaster.Dms.Providers adds provider-neutral file-version snapshots, independent history/download/restore/removal capability contracts and separate version-upload timestamps. Released CompuMaster.Ocs 2026.10.12 adapters are enabled for supported authenticated cloud services. Discovery preserves provider/file identities and endpoint-shaped nested paths; unavailable or denied version services remain errors.
- CompuMaster.Dms.BrowserUI adds localized, permission-gated version history and actions, safe temporary historical downloads, mutation confirmations and metadata refresh. Permissions are distinct from provider capabilities; callers reload current metadata after writes. Existing synchronous worker calls do not claim active cancellation.
- Update provider defaults to the actually published CompuMaster.CenterDevice.Rest, CompuMaster.Scopevisio.OpenApi and CompuMaster.Scopevisio.Teamwork 2026.10.13 packages. CenterDevice supplies log4net 3.5.0 transitively. CompuMaster.Ocs 2026.10.12, WebDav.Client 2.9.0 and RestSharp 112.1.0 remain selected. Explicit source overrides and normal NuGet dependency-floor semantics remain available.
- Fix Scopevisio instance authorization and reject mismatched account contexts (#109). Preserve the originating row for outgoing Explorer file drags (#84) and guard remote drag callback failures.
- Clarify upload preparation, logical-byte progress and batch estimates (#107/#108). Correct permission-aware tree renaming, conflict decisions and identity-bound replacements, internal remote moves, root upload targets, tree refresh/selection and missing-folder-ID fallback (#110-#114).
- Improve localized captions, dialog text measurement/layout, inherited icons and native DPI acceptance coverage. Coordinate workstation GUI notices and capture callback failures in tests. Existing physical/native acceptance limits remain distinct from isolated checks.
- Keep transfer recovery actions visible in bounded windows at large localized font sizes, with complete progress/error text in a scrollable viewport (#121).
- Retain bounded internal OCS discovery outcomes, failure phases and numeric HTTP diagnostics without exposing credentials or interrupting the generic WebDAV fallback (#122). This improves diagnosis and does not establish that every deployment enables sharing.
- Preserve classic ownCloud/Nextcloud sharing discovery when optional spaces or product-fingerprint metadata is absent, null or has an unrelated JSON type. Required sharing capabilities and policy flags still determine support; only an explicit Boolean spaces capability selects Infinite Scale.
- Serialize the complete normal remote CI matrix with one job at a time while preserving its per-server locks, filters and OS/backend coverage. Cross-repository/local server coordination remains required.

Generic/manual WebDAV version services remain unsupported.

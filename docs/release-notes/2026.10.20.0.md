# CompuMaster.Dms 2026.10.20.0

## CompuMaster.Dms.Providers

- Disables the fixed 30-HTTP-requests-per-minute quota by default for WebDAV, Nextcloud and ownCloud WebDAV transports while retaining two active requests per origin.
- Adds `WebDavDmsProvider.ConfigureRequestRateLimit(Uri, int?)` to explicitly enable a known quota before the origin's first request. The setting is shared across instances and URL paths; Nothing disables the quota.
- Applies HTTP 429/503 cooldowns across WebDAV instances and queued requests, honoring Retry-After and falling back to bounded backoff with jitter. Ambiguous writes are not automatically replayed.
- Adopts the corresponding CompuMaster.CenterDevice.Rest and CompuMaster.Scopevisio.Teamwork releases so Teamwork uses three shared active HTTP requests with no fixed minute quota by default. Legacy provider worker fallbacks retain their serialization.

## CompuMaster.Dms.BrowserUI

- Consumes the updated provider transport defaults. No BrowserUI workflow or metadata-query optimization is included.

The changed admission defaults are intentional. Existing public signatures remain available. Configured minute limits, concurrency, cancellation and server-directed cooldowns remain independent. OCS sharing transports retain their separate behavior.

## Validation infrastructure

- Pins the request-policy SDK and Teamwork adoption sources for combined isolated validation and includes request-policy regressions in named platform/runtime samples.
- Updates the native live package guard to require the exact SDK 2026.10.20, Teamwork 2026.10.20, OpenScope 2026.10.16 and OCS 2026.10.12 combination.

Full Windows/.NET 8 tests and named Linux/macOS/.NET Framework samples are reported separately in the release evidence; isolated tests do not establish real-server behavior.
